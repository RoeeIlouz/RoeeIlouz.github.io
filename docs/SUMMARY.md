# RoeeIlouz.github.io - Project Summary & Status

## System Status
- **Framework**: Astro 5 (Static Site Generator) & TypeScript
- **Styling**: Vanilla CSS3 (Custom Design System, Glassmorphism & Micro-animations)
- **Domain**: https://roee.ilouz.xyz (GitHub Pages with custom CNAME and HTTPS)
- **CI/CD**: GitHub Actions automated build & deployment workflow

## Key Architecture & Features
- **Localization (i18n)**: 100% static pre-rendered bilingual parity for English (`/`) and Hebrew (`/he/`, `dir="rtl"`).
- **Flagship Showcase**: ROCIs Tasks (Flutter/Dart productivity app on Google Play) and ROCIs Apps ecosystem.
- **Homelab Section**: Live-audited specs and topology for the 24/7 Raspberry Pi 5 node (8GB RAM, 1TB NVMe, Raspberry Pi OS Lite 64-bit, Zero Trust ingress, and 30+ Docker Compose services).
- **Design Tokens**: Standardized with the Obsidian Charcoal & Crimson Glow design system.
- **Performance**: Zero runtime JS bloat, high accessibility, and optimal Lighthouse performance.
